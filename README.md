# Event Force Management System

## 📌 Project Overview

The **Event Force Management System** is a Salesforce-based application designed to manage and organize event-related activities efficiently.

The system helps event organizers manage events, venues, volunteers/staff, participants, and event status in a centralized platform. It reduces manual work and makes event management easier and more organized.

## 🎯 Objectives

- To manage event details in one place.
- To manage venues and their availability.
- To manage event staff/volunteers.
- To track event status and schedules.
- To reduce manual data entry and paperwork.
- To improve event management and coordination.

## 👥 Users

- **Event Organizer** – Creates and manages events.
- **Event Staff/Volunteer** – Helps manage event activities.
- **Administrator** – Manages system data and users.
- **Participants** – Can be registered for events.

## ⚙️ Main Features

### 1. Event Management
- Create and manage events.
- Store event name, date, time, and description.
- Track event status.

### 2. Venue Management
- Manage venue information.
- Check venue availability.
- Assign venues to events.

### 3. Staff/Volunteer Management
- Store staff or volunteer details.
- Assign staff to events.
- Manage event responsibilities.

### 4. Participant Management
- Register participants for events.
- Maintain participant information.
- Track event participation.

### 5. Event Status Tracking
The system can track different event statuses such as:
- Planned
- Ongoing
- Completed
- Cancelled

### 6. Scheduling
Events can be scheduled based on date and time. This helps organizers avoid scheduling conflicts.

## 🔄 Project Workflow

1. Administrator creates event details.
2. Venue is selected and assigned to the event.
3. Staff/volunteers are assigned.
4. Participants are registered.
5. Event schedule is maintained.
6. Event status is updated.
7. After the event, the status is changed to **Completed**.
